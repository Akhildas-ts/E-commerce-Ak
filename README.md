## Introduction
This project is a fully functional e-commerce platform built using Go, Gin, and GORM. It includes user authentication, product management, payment processing through Razorpay, and OTP verification via Twilio.

## Features
- User registration and authentication
- Product listing and detail pages
- Shopping cart functionality
- Order placement and management
- Payment processing with Razorpay
- OTP verification for secure user authentication
- API documentation with Swagger

## Technologies Used
- **Go**: Programming language for backend development
- **Gin**: Web framework for building APIs
- **GORM**: ORM library for interacting with the database
- **Swagger**: API documentation tool
- **Razorpay**: Payment gateway integration
- **Twilio**: OTP verification service
- **PostgreSQL/MySQL**: Database
